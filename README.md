# AI Resume Studio

An intelligent resume builder, analyzer, ATS optimizer, and computer vision resume assistant.

## Current Status

Project development is in progress.

## Planned Features

- Resume Builder
- Resume Upload and Parsing
- NLP Skill Extraction
- ATS Compatibility Analysis
- Job Description Matching
- Resume Improvement Suggestions
- Bullet Point Analysis
- Computer Vision Resume Quality Analysis
- Professional Resume Templates
- PDF Export
- Streamlit Deployment

## Technology Stack

- Python
- Streamlit
- Scikit-learn
- spaCy
- Sentence Transformers
- OpenCV
- PyMuPDF
- Tesseract OCR
- EasyOCR
- ReportLab
